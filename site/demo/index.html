LOCAL ENGINE

IndexedDB transactions serialize browser writes, including across tabs. This demonstrates the behavior; Java/PostgreSQL concurrency is tested separately in the repository.

EXPERIMENT 01

32 retries. One charge.

Submit 32 identical $25 transfers at once, using the same request key. The first posts; the rest return the exact same receipt.

EXPERIMENT 02

40 requests. Limited funds.

Why this matters

A lost network response shouldn’t mean a duplicate charge. And two payments can’t spend the same balance. Explore the Java implementation for PostgreSQL row locks, durable idempotency, and Kafka audit events.

UNDERSTAND YOUR WORKSPACE

Hands-on. On your device.

This is a working browser sandbox. Accounts, balances, request keys, and journal entries are saved in IndexedDB on this device. Reloading the page keeps your workspace; another browser starts its own.

It doesn’t call the Java API, PostgreSQL, Redis, or Kafka. The repository contains that separate backend, with real-service integration tests. GitHub Pages serves static websites and cannot run Java services.

Use fictional names. No signup, real money, or bank information is needed. Clearing browser storage removes your demo data. Private browsing may not retain it.
