A successful request is the easy part. The real work is preserving financial invariants when everything else is uncertain.

DATABASE FIRST

Correctness lives below the API.

A deferred database constraint requires the exact debit and credit before commit. Journal records are immutable; corrections require a new transfer.

FAILURE AWARE

A broker outage doesn’t lose the event.

The event intent commits with the transfer. A publisher retries pending events, using stable event IDs so downstream consumers can deduplicate.
